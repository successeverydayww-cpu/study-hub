MODULE 1 — Regression Analysis

Regression finds the line (or curve) that best fits a set of data points, so you can predict one variable from another.

1.1 The Least-Squares Line (y = a + bx)

The best-fit line minimises the sum of squared vertical deviations between the points and the line. The constants a (intercept) and b (slope) come from the normal equations:

Σy = na + bΣx
Σxy = aΣx + bΣx²

Or directly with means:

b = (Σxy − n·x̄·ȳ) ⁄ (Σx² − n·x̄²)
a = ȳ − b·x̄

The slope b tells you how much y changes for every 1-unit rise in x.

1.2 The Least-Squares Parabola (y = a + bx + cx²)

When data curves, fit a second-degree curve. Three unknowns → three normal equations:

Σy = na + bΣx + cΣx²
Σxy = aΣx + bΣx² + cΣx³
Σx²y = aΣx² + bΣx³ + cΣx⁴

1.3 Multiple Regression (y = a + b₁x₁ + b₂x₂)

Predicting y from two independent variables needs three normal equations:

Σy = na + b₁Σx₁ + b₂Σx₂
Σx₁y = aΣx₁ + b₁Σx₁² + b₂Σx₁x₂
Σx₂y = aΣx₂ + b₁Σx₁x₂ + b₂Σx₂²

1.4 Standard Error of Estimate (Sy·x)

Measures the average scatter of points about the regression line. Smaller = tighter fit.

Sy·x = √[ (Σy² − aΣy − bΣxy) ⁄ (n − 2) ]
A perfect fit gives Sy·x = 0. If Sy·x is small relative to the y-values, predictions from the line are reliable.

1.5 Worked Example — Fitting the Line

Example. Fit y = a + bx to: x = 1,2,3,4,5 and y = 2,3,5,4,6.

Σx = 15, Σy = 20, Σxy = 1(2)+2(3)+3(5)+4(4)+5(6) = 67, Σx² = 55, n = 5, x̄ = 3, ȳ = 4.

b = (67 − 5·3·4) ⁄ (55 − 5·9) = (67 − 60) ⁄ (55 − 45) = 7 ⁄ 10 = 0.7
a = 4 − 0.7(3) = 1.9

Regression line: y = 1.9 + 0.7x

Predict at x = 6: y = 1.9 + 0.7(6) = 6.1
Using the line inside the observed x-range is interpolation (safe); predicting far outside the range is extrapolation (risky).

MODULE 2 — Correlation

Correlation measures the strength and direction of the relationship between two variables.

2.1 Pearson's Linear Correlation Coefficient (r)

r = (n·Σxy − Σx·Σy) ⁄ √[(nΣx² − (Σx)²)(nΣy² − (Σy)²)]
  • r always lies between −1 and +1
  • r = +1 → perfect positive correlation (points rise exactly)
  • r = −1 → perfect negative correlation (points fall exactly)
  • r = 0 → no linear relationship
|r| valueInterpretation
0.90 – 1.00Very high correlation
0.70 – 0.90High correlation
0.40 – 0.70Moderate correlation
0.00 – 0.40Low correlation

2.2 Spearman's Rank Correlation (ρ or R)

Used when data are ranks (or ranked), or for data not strictly linear. Rank both variables (1 = highest or 1 = lowest, consistently), find d = difference in ranks for each item:

ρ = 1 − [ 6·Σd² ⁄ n(n² − 1) ]
Tied ranks: give tied items the average of the ranks they share, then apply a tie correction. For small numbers of ties, the simple formula is still commonly used.

2.3 Worked Example — Spearman

Example. Two judges rank 5 contestants. Judge A: 1,2,3,4,5. Judge B: 2,1,4,3,5.

d = (1−2, 2−1, 3−4, 4−3, 5−5) = (−1, 1, −1, 1, 0); d² = 1+1+1+1+0 = 4

ρ = 1 − 6(4) ⁄ [5(25−1)] = 1 − 24⁄120 = 1 − 0.2 = 0.8
Strong agreement between the judges.
Correlation ≠ causation. Two variables moving together does not prove one causes the other.

MODULE 3 — Hypothesis Testing

3.1 The Two Hypotheses

  • Null hypothesis (H₀): the "nothing is happening" claim — no difference, no effect, the parameter equals some value. Assumed true until evidence says otherwise.
  • Alternative hypothesis (H₁): what you accept if H₀ is rejected — there IS a difference/effect.

3.2 Errors

H₀ trueH₀ false
Reject H₀Type I error (α)Correct ✓
Accept H₀Correct ✓Type II error (β)
  • Type I error: rejecting H₀ when it is actually true (false alarm). Probability = α = the significance level.
  • Type II error: accepting H₀ when it is actually false (missed detection). Probability = β.
  • Power of a test = 1 − β = probability of correctly rejecting a false H₀.

3.3 Levels of Significance (α)

Common significance levels:

LevelMeaning
α = 0.05 (5%)5% risk of Type I error — standard choice
α = 0.01 (1%)Stricter — harder to reject H₀

The level chosen fixes the critical value that the test statistic must beat.

3.4 Critical Values of Z (standard normal)

TestαCritical |Z|
Two-tailed5% (0.025 each side)1.96
Two-tailed1% (0.005 each side)2.575
One-tailed (right)5%1.645
One-tailed (right)1%2.33
One-tailed (left)5%−1.645

3.5 One-Tailed vs Two-Tailed

  • Two-tailed: H₁ says "different from" (≠). Rejection region split between both tails.
  • One-tailed (right): H₁ says "greater than" (>). Whole rejection region in right tail.
  • One-tailed (left): H₁ says "less than" (<). Whole rejection region in left tail.

3.6 The Z-Test and Decision Rule

Testing a mean with known population standard deviation σ:

Z = (x̄ − μ) ⁄ (σ ⁄ √n)
Decision rule. At α = 0.05, two-tailed: reject H₀ if |Z| > 1.96; otherwise accept (do not reject) H₀. The acceptance region is the middle 95% of the curve; the rejection (critical) regions are the two tails beyond ±1.96.

3.7 Full Worked Example

Example. A machine fills bottles to 500 ml, σ = 5 ml. A sample of n = 40 gives x̄ = 502 ml. Test at 5% significance whether the mean fill has changed.

H₀: μ = 500    H₁: μ ≠ 500 (two-tailed)

Z = (502 − 500) ⁄ (5 ⁄ √40) = 2 ⁄ 0.7906 = 2.53

Critical value: ±1.96. Since 2.53 > 1.96 → reject H₀. The mean fill HAS changed at the 5% level. (Note: at the 1% level, 2.53 < 2.575, so we would accept H₀ — the conclusion depends on α.)
The general procedure: (1) state H₀ and H₁, (2) choose α, (3) compute the test statistic, (4) find the critical value and region, (5) decide: reject or accept H₀, (6) state the conclusion in plain words.

MODULE 4 — Probability Distributions

4.1 Binomial Distribution

Models the number of successes in a fixed number n of independent trials, each with the same probability p of success. Conditions: fixed n, two outcomes only, constant p, independent trials.

P(X = r) = ⁿCr · pr · qn−r   where q = 1 − p
Mean = np    Variance = npq    SD = √(npq)
Example (coin toss). A fair coin is tossed 4 times. Probability of exactly 2 heads?

n = 4, r = 2, p = q = 0.5
P = ⁴C₂ (0.5)²(0.5)² = 6 × 0.0625 = 0.375

Mean = np = 2 heads; Variance = npq = 1.

4.2 Poisson Distribution

Models the number of events in a fixed interval when events happen independently at a constant average rate λ (e.g. calls per hour, defects per page). Key property: mean = variance = λ.

P(X = r) = e−λ · λr ⁄ r!
Example. A receptionist receives an average of 3 calls per minute. Probability of exactly 2 calls in a minute?

λ = 3, r = 2
P = e⁻³ · 3² ⁄ 2! = 0.04979 × 9 ⁄ 2 = 0.2241

At least 1 call: P = 1 − P(0) = 1 − e⁻³ = 1 − 0.0498 = 0.9502

4.3 Poisson Approximation to the Binomial

When n is large and p is small (rule of thumb: n ≥ 50, p ≤ 0.1), the binomial is well approximated by the Poisson with:

λ = np
Example. A factory makes 200 items; 1% are defective. Probability of exactly 3 defectives?

Binomial: n = 200, p = 0.01 → λ = np = 2
Poisson: P(X=3) = e⁻² · 2³ ⁄ 3! = 0.1353 × 8 ⁄ 6 = 0.1804
